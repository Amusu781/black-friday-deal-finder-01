Deal Beacon: a fast, filterable Black Friday deal finder with 38 real deals checked 27 Nov 2026 across Amazon, Best Buy, Target and Walmart. Every deal carries its product, store, sale price, usual price, discount, store link and check time, plus an honest verdict — new low, strong price or routine sale — with the evidence behind it. Search, category, store and discount filters all work, the best deals sort first, and the same product is compared across stores where both carry it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

That copies `app/` and `screenshots/` into `out/` and writes `out/dossier.json`. To open the site itself, serve `app/` with any static server — for example `python3 -m http.server 8080 --directory app` — then open http://localhost:8080.
